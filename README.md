# Market Study Demo - Modern Website Development Practices

This folder contains the **source code deliverables**:
- A **static + responsive web page** (`index.html`) using HTML + CSS.
- **Interactivity** (`script.js`): theme toggle, cookie consent, form validation, toast notifications, and fetching local JSON tips.
- A **Tic-Tac-Toe game** (`tictactoe.html`, `tictactoe.js`, `tictactoe.css`) with score saved to localStorage.

## How to run locally (recommended)
Some features (like `fetch()` for `data/tips.json`) require a local server.

### Option A: Python (quick)
```bash
cd market-study-web
python -m http.server 8000
```
Open: http://localhost:8000

### Option B: VS Code Live Server
Right click `index.html` -> "Open with Live Server".
